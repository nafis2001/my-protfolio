# Research and creative decisions

The creative system follows the supplied Attention Studio brief: disciplined source-order grids, oversized cobalt identity, restrained italic contrast, and a tactile typographic experiment rather than generic stock imagery. No existing portfolio composition, source, or artwork was copied. The visible poster is an interface experiment made for this site, clearly identified as such.

Official sources attempted during implementation:

- Astro content collections: https://docs.astro.build/en/guides/content-collections/
- Cloudflare Astro static deployment: https://developers.cloudflare.com/pages/framework-guides/deploy-an-astro-site/
- Cloudflare limits: https://developers.cloudflare.com/pages/platform/limits/
- Google Search Central: https://developers.google.com/search/docs/fundamentals/seo-starter-guide

All four requests returned proxy 403; they were not read. Installed Astro 7 exports, type declarations, package CLI behavior, font package licenses, production builds and browser execution supplied implementation evidence. Current Cloudflare terms still need verification before account configuration. No keyword-volume research or rankings are claimed.

Typography is self-hosted with Latin subsets and swap delivery. Full OFL licenses are retained in public/licenses. The small symbol font subset avoids system-dependent emoji and missing-glyph rendering. No motion library is needed. CSS handles transforms/entrances; only /lab loads the composition script. JavaScript is not required to read the site or contact Nafis directly. Gallery filters progressively enhance normal project links. Native details gives the mobile menu keyboard behavior without a custom modal or focus trap.

The SVG export uses textContent and XMLSerializer, never HTML insertion from input. Export uses generic fonts for portable editable vectors; exact typography can vary across systems. The poster tool is entirely local. No user text leaves the browser.
